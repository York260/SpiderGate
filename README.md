# SpiderGate 守門員

打開黑名單上的 App 或網站時，會直接被送回桌面。想用的話，打開守門員 App 申請，說服守門員 AI（Claude）才能使用。

## 兩層把關

- **絕對禁止**：小說、劇、AI 劇、短劇類的 App、網站、關鍵字。直接踢出去，不談判。
- **許可制**：YouTube、IG 等。講出正當理由＋預估時間，守門員放行「那一個」，時間到自動鎖回。放行期間畫面出現禁止內容（例如在 YouTube 點開短劇），一樣會被踢出去。

- **運動獎勵**：真的在運動，可以邊動邊「聽」小說 30 分鐘，可連任（一天最多 4 次）。守門員至少問滿 3 輪才可能放行，會對照計步器；時間到會自動暫停播放。
- **返校專車**：搭返校專車時可以聽小說 1 小時，一天一次。守門員至少問 2 輪確認你真的在車上，時間到自動暫停播放。

守門員個性：像蜘蛛人，友善、會開玩笑，循循善誘，不說教。

## 寫死的規則（AI 改不了）

- 一次最多放行 30 分鐘
- 一天最多放行 5 次
- 被拒絕後冷卻 15 分鐘
- 最多談 6 輪，沒結論視同拒絕
- 名單只能加，不能刪

## 安裝與設定

1. 到 Releases 下載 `gatekeeper.apk` 並安裝。
2. Android 13 以上：先到「設定 → 應用程式 → 守門員」，點右上角 ⋮，選「允許受限制的設定」。不做這步，無障礙服務會打不開。
3. 打開守門員：
   - 按「開啟無障礙服務」，找到「守門員」並開啟。
   - 按「啟用裝置管理員」。
   - 貼上 Claude API 金鑰（console.anthropic.com 申請），按「儲存金鑰」。
4. 按「跟守門員談談」，測試能不能連上。

## 上鎖（最後一步）

1. 關掉「開發人員選項」和「USB 偵錯」。
2. AppBlock 開嚴格模式，勾選封鎖「設定」，並開啟「封鎖不支援的瀏覽器」。
3. 請同學幫你設一組 PIN，不要讓你知道。

這樣串起來：想移除守門員就得進設定，想進設定就得解開 AppBlock，想解開 AppBlock 就得去說服同學。

## 已知限制

- 瀏覽器只支援 Chrome、Firefox、Edge、Samsung、Brave、Opera。其他瀏覽器交給 AppBlock 擋。
- LINE、IG 這類 App 裡內建的瀏覽器擋不到網址，要靠把 App 本身列進黑名單。
